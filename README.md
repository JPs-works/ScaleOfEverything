# Scale of Everything

Compare the sizes of 32 things, from the Planck length (10⁻³⁵ m) to the
observable universe (10²⁷ m), in two side-by-side panels. Built with React 19,
three.js and React Three Fiber; embedded on [jakeparr.dev](https://jakeparr.dev)
under `/apps/scale-of-everything/`.

## Using it

- **← →** step to smaller / larger items. **Keep** (L / R) holds one side while the other steps.
- **Scroll, pinch or drag** (or the scale bar at the bottom) to travel smoothly through scale; the items follow.
  When embedded, the first click activates the view so the host page keeps scrolling until then.
- **Scale**: *fit left* / *fit right* share one scale between both panels (S swaps), *Separate scales* (F) fits each item.
- Too small to see → a ring marks it. Bigger than the panel → its top edge is shown, with a mini-map of where the view sits.
- **/** opens the item list, **?** the help & credits, **Esc** closes dialogs.
- The URL hash is a deep link, e.g. `#left=human&right=mount-everest&scale=right`.

## Development

Dependencies come from the root npm workspace of jakeparr.dev (run `npm install` there, not here).

```sh
npm run dev                 # Vite dev server
npm run build               # tsc --noEmit && vite build  → dist/
npm run preview             # serve dist/ (base /apps/scale-of-everything/)
npm test                    # formatter unit tests (tsx scripts/test-formatting.ts)
```

## Code map

- `constants.ts` — the catalogue: size in metres, which dimension it measures, asset path.
- `App.tsx` — state (items, keep, scale mode), deep link, keyboard / wheel / pointer input.
- `components/Stage3D.tsx` — lazy-loaded 3D chunk: one persistent canvas, one drei `View` per panel.
- `components/ItemVisual3D.tsx` — per-panel scene: orthographic camera (1 unit = 1 px), item scaling,
  edge/horizon mode, asset error boundary, load timeout.
- `components/visuals/` — procedural scenes for every item, plus GLB / textured-sphere loaders.
- `components/InfoPanel.tsx` — per-panel overlay: labels, Keep, scale bar, ring marker, mini-map.
- `utils/formatting.ts` — length / ratio formatting (`npm test`).

## Assets

`public/assets3d/` is generated by `scripts/process-assets.ts` from raw downloads
(sources and licences listed in that script and in `public/assets3d/credits.json`,
shown in the app's Credits panel):

```sh
npx tsx scripts/process-assets.ts --src <download-dir> [--only id,id] [--inspect]
```

The script centres each model, scales it so the dimension `size` refers to is 1 unit,
simplifies it, converts textures to WebP ≤ 2K and meshopt-compresses it, enforcing
1.5 MB per file and 25 MB in total. Items without a suitable freely licensed model
are drawn procedurally in code.
